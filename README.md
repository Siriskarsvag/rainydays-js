# JavaScript 1 - Rainydays

First project using JavaScript. 

## Description

An improved version of the Rainy days online store featuring API integration, dynamic product rendering and shopping cart functionality. 

Online store features:

- API product fetching
- Featcing Product details
- LocalStorage and shopping cart functionality
- Checkout process
- Confirmation page

## Built With
- CSS
- HTML
- JavaScript
- API handeling
